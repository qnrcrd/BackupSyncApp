#  BackupSyncApp

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple)](https://dotnet.microsoft.com/)
[![Platform](https://img.shields.io/badge/Platform-Windows-blue)](https://www.microsoft.com/windows)
[![Release](https://img.shields.io/github/v/release/qnrcrd/BackupSyncApp?label=Release)](https://github.com/qnrcrd/BackupSyncApp/releases)

**BackupSyncApp** — простое десктопное приложение для автоматического резервного копирования файлов на USB-накопители. Разработано по принципу *«настроил и забыл»* для пользователей без технической подготовки.

---

##  Основные возможности

-  **Автоматическое копирование** — мгновенная реакция на подключение USB через WMI-мониторинг
-  **Шифрование** — ZIP-архивы с паролем, защищённым через Windows DPAPI
-  **Система напоминаний** — гибкое расписание (ежедневно/еженедельно/ежемесячно/ежегодно)
-  **Работа в трее** — фоновый режим с уведомлениями Windows
-  **Автозапуск с Windows** — без прав администратора (HKCU Registry)
-  **Туториал** — интерактивное обучение при первом запуске
-  **Локализация** — полная поддержка русского и английского языков

## Установка

### Через установщик
1. Скачайте последнюю версию из раздела [Releases](https://github.com/qnrcrd/BackupSyncApp/releases)
2. Запустите `BackupSyncApp_Setup_1.0.0.exe`
3. Следуйте инструкциям установщика
4. Запустите приложение с рабочего стола или из меню Пуск

### Из исходного кода
1. Выполните в консоли комманды ниже
```bash
git clone https://github.com/qnrcrd/BackupSyncApp.git
cd BackupSyncApp
```
2. Откройте BackupSyncApp.sln в Visual Studio 2022+
3. Выберите конфигурацию Release и нажмите Build

##  Как использовать

### Быстрый старт (3 шага)
1. **Добавьте папки** — выберите источники для резервного копирования.
2. **Настройте USB** — укажите целевой накопитель и включите авто-копирование.
3. **Готово!** — подключите флешку, и бэкап запустится автоматически.

### Ручное копирование
Переключитесь в режим «Ручное копирование», выберите целевой диск и нажмите «Начать копирование».

### Настройка напоминаний
В разделе «Настройки» включите напоминания и выберите периодичность. Приложение напомнит о бэкапе при запуске и перед выходом, если в назначенный день копия не была создана.

## ️ Архитектура и технологии

Приложение построено на паттерне **MVVM** (Model-View-ViewModel) с использованием **WPF** и **XAML**.

### Технологический стек
- **Язык:** C# 12
- **Фреймворк:** .NET 10 / WPF
- **Архитектура:** MVVM
- **Мониторинг USB:** WMI (Windows Management Instrumentation)
- **Шифрование:** Windows DPAPI
- **Архивация:** System.IO.Compression (ZIP)
- **Установщик:** Inno Setup

### Структура проекта
```text
BackupSyncApp/
├── App.xaml                    # Точка входа, системный трей
├── Views/
│   ├── MainWindow.xaml         # Главный интерфейс
│   └── TutorialWindow.xaml     # Туториал первого запуска
├── ViewModels/
│   └── MainViewModel.cs        # Бизнес-логика и команды
├── Models/
│   └── AppSettings.cs          # Сериализация настроек
├── Services/
│   ├── BackupManager.cs        # Алгоритм Staging
│   ├── UsbDriveWatcher.cs      # WMI-мониторинг
│   └── ArchiveService.cs       # ZIP + шифрование
└── Resources/
    └── Localization/           # Строки RU/EN
```
##  Безопасность
Пароли архивов и пути к копируемым папкам шифруются через DPAPI и привязаны к локальной учётной записи Windows. Настройки хранятся в %localappdata%\BackupSyncApp\ и недоступны другим пользователям.

## Системные требования
- Windows 10/11 (x64)
- .NET 10 Runtime (устанавливается автоматически вместе с приложением)
- ~30 MB свободного места на диске
- внешний накопитель для резервных копий
